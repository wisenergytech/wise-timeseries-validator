# R Shiny (golem + bslib) — Conventions Wise

## Version

R 4.3+, Shiny latest stable, golem framework, bslib for theming.

## Project Setup

- Use `golem::create_golem()` to scaffold new projects (golem apps are R packages).
- Use `renv` for dependency management (lockfile-based, reproducible).
- Use `bslib` for all UI theming — no raw CSS for colors/fonts.

## Modules

- Use `golem::add_module(name = "dashboard")` to create modules.
- One file per module in `R/`, prefixed with `mod_` (e.g., `mod_dashboard.R`).
- Each module exports `mod_<name>_ui(id)` and `mod_<name>_server(id)` functions.
- Use `golem::add_fct("helpers")` for topic-focused functions (`R/fct_helpers.R`).
- Use `golem::add_utils("formatters")` for misc utilities (`R/utils_formatters.R`).

## Theming with bslib

All visual theming MUST go through `bslib::bs_theme()` — do NOT write raw CSS for colors, fonts, or spacing. Define the Wise theme in `R/fct_theme.R`:

```r
wise_theme <- function() {
  bslib::bs_theme(
    version = 5,
    bg = "#F6F7F8",
    fg = "#171616",
    primary = "#1D4345",
    secondary = "#E9A345",
    success = "#BCC9B9",
    danger = "#FF0000",
    base_font = bslib::font_google("Raleway"),
    heading_font = bslib::font_google("Raleway"),
    "navbar-bg" = "#1D4345"
  )
}
```

Apply in `R/app_ui.R`:
```r
bslib::page_sidebar(
  title = "Wise App",
  theme = wise_theme(),
  ...
)
```

## Environment Variables

- Load via `Sys.getenv()` or `golem::get_golem_config()`.
- Secrets (`SUPABASE_SERVICE_ROLE_KEY`, API keys) MUST only be read server-side in `R/` modules. They MUST NOT be sent to the UI.

## HTTP Client

- Use `httr2` for all external API calls.
- Centralize API clients in `R/utils_api.R`.
- All external API calls happen server-side (Shiny runs entirely on the server).
- HTTPS MUST be enforced for all external calls.

## Error Handling

- Wrap API calls in `tryCatch()`.
- Display user-friendly messages via `showNotification()` or `validate(need(...))`.
- Log technical details to stdout with structured prefixes (e.g., `[auth]`, `[api]`).
- Use `message()` for info logs, `warning()` for warnings, `stop()` for errors.
